## Kesimpulan Umum

Repository ini mendokumentasikan perjalanan belajar Data Science selama satu semester (Pertemuan 1–13) yang terbagi dalam beberapa fase:

**Fase 1 (Pertemuan 1–4): Fondasi**
Mempelajari dasar Python untuk data science, struktur data dengan NumPy dan Pandas, pembersihan data (missing values, outlier, duplikasi), serta analisis statistika deskriptif (ukuran pemusatan, distribusi, korelasi).

**Fase 2 (Pertemuan 5–7): Analisis & Persiapan**
Visualisasi data menggunakan Matplotlib dan Seaborn, persiapan data untuk machine learning (encoding, scaling, train-test split), dan pengenalan Regresi Linier sebagai algoritma ML pertama.

**Fase 3 (Pertemuan 9–11): Machine Learning**
Klasifikasi menggunakan Logistic Regression dan Decision Tree, evaluasi model dengan Confusion Matrix dan metrik klasifikasi (Accuracy, Precision, Recall, F1-Score), Random Forest sebagai metode ensemble, penanganan imbalanced dataset dengan SMOTE, serta unsupervised learning melalui K-Means dan Hierarchical Clustering.

**Fase 4 (Pertemuan 12–13): Advanced Topics**
Penemuan pola dalam data transaksi menggunakan Algoritma Apriori (Market Basket Analysis), sistem rekomendasi berbasis Collaborative dan Content-Based Filtering, pengantar Artificial Neural Network (ANN/MLP), serta pemrosesan teks dengan TF-IDF untuk analisis sentimen.

Secara keseluruhan, mata kuliah ini memberikan pemahaman menyeluruh tentang alur kerja data science: dari pengumpulan dan pembersihan data, eksplorasi dan visualisasi, hingga pembuatan model prediktif dan analitis yang dapat diaplikasikan pada masalah nyata.
